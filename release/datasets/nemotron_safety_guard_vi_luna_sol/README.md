# Nemotron Safety Guard Vietnamese Luna/Sol Translation

This card describes a Vietnamese machine-translated derivative of the English
split of NVIDIA's
[`Nemotron-Safety-Guard-Dataset-v3`](https://huggingface.co/datasets/nvidia/Nemotron-Safety-Guard-Dataset-v3).
It is an independent research contribution and is not an official NVIDIA
language release.

## Dataset summary

- Source records: 45,416.
- Vietnamese records: 45,416, joined by immutable source UID.
- Translation providers: 45,060 Luna and 356 Sol Web.
- Final structural audit: zero missing, extra, duplicate, or structurally
  invalid UIDs.
- Splits: original upstream train/validation/test assignments are preserved.
- Labels: upstream binary safety and N23 metadata are preserved, not
  regenerated by the translation model.
- Downstream status: not yet trained/evaluated; reported model results in the
  GitHub repository use the earlier Gemini translation condition.

The generated P/R/PR training views are materializations of each aligned source
record. The frozen comparison protocol uses only P and PR for the final no-R
experiments; R is excluded.

## Translation method

Luna Light handled the normal path with fresh sessions, length-aware batches,
per-UID retry state, immediate saving of valid records, and hard validation.
Long, structured, leetspeak, or repeatedly invalid records were routed through
special prompts or to Sol Web. All returned members of a batch were retained;
validation was record-level rather than all-or-nothing.

The complete method, prompt versions, validator boundaries, and hard-case
analysis are maintained in the companion GitHub repository.

## Intended uses

- research on Vietnamese and multilingual safety classifiers;
- paired translation-quality experiments;
- robustness evaluation by language, safety class, N23 category, view, length,
  leetspeak, and jailbreak features;
- controlled comparison with the Gemini-derived translation.

## Limitations and risks

- This is machine-translated safety data, not native Vietnamese annotation or
  a CultureGuard-equivalent cultural adaptation.
- Structural validation is not proof of perfect semantic equivalence.
- The corpus intentionally contains harmful and offensive material, including
  violence, self-harm, sexual content, illegal activity, hate, and jailbreaks.
- Seven accepted records are documented special cases and two records are
  accepted known issues; users should consult the released quality manifest.
- No downstream improvement claim is supported until the frozen matched
  training/evaluation protocol is run.
- Users remain responsible for privacy, publicity, moral-rights, and local-law
  review beyond the copyright license.

## Reproducibility

Release artifacts should include a schema manifest, split counts, per-file
SHA-256 checksums, quality summary, and the source UID for every record. Raw API
credentials, session logs, and provider account data are never part of the
dataset.
