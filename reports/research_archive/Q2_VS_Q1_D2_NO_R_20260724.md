# Q2 versus Q1 and D2 — exact-ID no-R comparison

Date: 2026-07-24

## Evaluation contract

- Exact intersection: 11,736 examples.
- Target mismatches: 0.
- Views: P and PR only; R is excluded from evaluation.
- Benchmarks: Nemotron test and SEA paired.
- Languages: English and Vietnamese, with 5,868 examples each.
- Primary Q1 mapping: `controversial -> unsafe` (conservative).

Runs:

- Q1: base/zero-shot `Qwen/Qwen3Guard-Gen-4B`.
- Q2: the same Qwen base plus the no-R EN+VI LoRA adapter trained on
  101,274 examples.
- D2: the previous `D2-NEMOTRON-GUARD-8B-VI-PILOT` adapter. It was
  trained on only 8,192 balanced EN+VI examples, including P, R, and PR,
  at context 1,024. The comparison below filters its evaluation to P/PR.

## Output contract and format

- Q1 emitted 4,683 `safe`, 1,682 `controversial`, and 5,371 `unsafe`
  native labels. The primary comparison maps `controversial` to
  Unsafe. Mapping it to Safe instead yields only 84.91% overall
  accuracy, still below Q2.
- Q2 emits only `Safety: Safe` or `Safety: Unsafe`. All 11,736 outputs
  parsed and passed its strict format.
- D2 emits the official Nemotron JSON and can report N23 categories.
  It parsed 11,735/11,736 no-R outputs.
- Q1 and Q2's native category ontology is not isomorphic to Nemotron
  N23, so neither is scored as N23.
- D2 remains the only one of these three runs that supports the N23
  task. On its prior full P/R/PR evaluation, N23 micro-F1 was 58.20%,
  macro-F1 47.49%, and exact match 51.73%.

The earlier Q1-to-D1 cascade (delegate Q1 `controversial` cases to D1)
scored 87.49%. Q2 alone scores 87.83%, 0.34 points higher, without
requiring a second 8B inference call.

## Scientific interpretation

The translated-data pipeline is useful for Qwen binary guard training:
Q2 gains 2.98 accuracy points in Vietnamese versus 2.39 in English,
and gains 3.21 points on SEA Vietnamese. Those gains are paired on
identical examples and statistically strong.

This is not yet a controlled proof that Vietnamese examples alone
caused the gain. Q2 changed several factors at once:

- 101,274 training examples instead of zero-shot Q1;
- both English and Vietnamese training data;
- forced binary output instead of Q1's three-way native verdict;
- context 2,048.

Likewise, Q2 versus D2 is not a pure architecture comparison:

- Q2 is a 4B Qwen model trained on 101,274 no-R P/PR examples.
- D2 is an 8B Nemotron model trained on only 8,192 examples, one third
  of which were R, with context 1,024.
- D2 solves official JSON plus N23, while Q2 solves a shorter binary
  output contract.

The clean causal follow-up is an English-only Qwen LoRA with the same
training count, optimizer settings, context, and binary contract as
Q2. Comparing that control against Q2 isolates the contribution of
Vietnamese translated data.
